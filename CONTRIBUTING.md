# Contributing to Awesome Persian LLM

Thank you for your interest in contributing to Awesome Persian LLM! This document provides guidelines for contributing to this curated list.

## How to Contribute

1. **Fork the repository** - Click the 'Fork' button at the top right of this page
2. **Clone your fork** - `git clone https://github.com/your-username/awesome-persian-llm.git`
3. **Create a branch** - `git checkout -b add-new-resource`
4. **Make your changes** - Add your resource following the guidelines below
5. **Commit your changes** - `git commit -m "Add [resource name]"`
6. **Push to your fork** - `git push origin add-new-resource`
7. **Create a Pull Request** - Go to your fork on GitHub and click 'New Pull Request'

## Contribution Guidelines

### General Rules

- **One resource per pull request** - This makes it easier to review and accept contributions
- **Check for duplicates** - Search the list to ensure your resource isn't already included
- **Working links** - Ensure all links are functional and point to the correct resource
- **English descriptions** - Write descriptions in English for accessibility
- **Relevant to Persian** - Resources must be specifically for Persian language or have significant Persian support

### Quality Standards

Resources should be:
- **High quality** - Well-maintained, documented, and useful to the community
- **Accessible** - Publicly available (open source, published papers, or accessible platforms)
- **Relevant** - Directly related to Persian LLMs, NLP, or language processing
- **Current** - Active projects, recent papers, or maintained tools

### Formatting Guidelines

#### General Format
```markdown
- [Resource Name](https://link-to-resource.com) - Brief description of what it is and why it's useful
```

#### Papers
- Include the paper title and link to arXiv, ACL Anthology, or official publication
- Add a brief description of the paper's contribution
- Format: `[Paper Title](link) - Brief description`

#### Models
- Include model name and link to model card or repository
- Mention model size if relevant (e.g., "148M parameters")
- Format: `[Model Name](link) - Description with key features`

#### Datasets
- Include dataset name and link to repository or download page
- Mention the type of data and size if relevant
- Format: `[Dataset Name](link) - Description of content and use case`

#### Tools
- Include tool name and link to repository or website
- Describe main features and use cases
- Format: `[Tool Name](link) - Description of functionality`

### Section Organization

- Add resources in **alphabetical order** within each subsection
- If a subsection doesn't exist but is needed, create it following the existing structure
- Place resources in the most specific relevant section

### What to Avoid

- ❌ Broken or dead links
- ❌ Duplicate entries
- ❌ Resources without Persian support
- ❌ Commercial promotions without substantial free/open resources
- ❌ Low-quality or unmaintained projects
- ❌ Personal projects without significant community adoption (unless exceptional)

### Examples of Good Contributions

✅ **Good Paper Addition:**
```markdown
- [ParsBERT: Transformer-based Model for Persian Language Understanding](https://arxiv.org/abs/2005.12515) - First BERT-based model specifically pre-trained on Persian corpora
```

✅ **Good Model Addition:**
```markdown
- [Persian RoBERTa](https://huggingface.co/HooshvareLab/roberta-fa-base) - RoBERTa model pre-trained on Persian text corpus
```

✅ **Good Dataset Addition:**
```markdown
- [FarsTail](https://github.com/dml-qom/FarsTail) - Persian natural language inference dataset for textual entailment
```

✅ **Good Tool Addition:**
```markdown
- [Hazm](https://github.com/sobhe/hazm) - Python library for Persian text processing including tokenization, stemming, and POS tagging
```

## Questions or Suggestions?

If you have questions or suggestions for improving this list or the contribution process:

1. Open an issue on GitHub
2. Use a descriptive title
3. Provide as much detail as possible

## Code of Conduct

- Be respectful and constructive in all interactions
- Welcome newcomers and help them contribute
- Focus on what is best for the community
- Show empathy towards other community members
